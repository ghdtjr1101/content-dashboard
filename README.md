# 콘텐츠 운영 대시보드

매일 올리는 AI 활용 릴스를 기획부터 분석까지 한 화면에서 관리하는 페이지.

- **기획판**: 예비 콘텐츠 ↔ 게시 순서를 끌어다 놓기, 카드를 눌러 대본·훅·키워드·링크·숫자 수정
- **일정**: 게시 순서와 설정(촬영일·첫 게시일·사이클 길이)으로 촬영·편집·게시·가이드 일정 자동 계산
- **분석**: 영상별 조회·좋아요·댓글·공유·저장 기록과 비교
- **운영 시트**: 계정 운영 규칙 (직접 수정 가능)

이 저장소에는 화면 코드만 있다. 내용은 비공개 저장소 `content-dashboard-data` 의 `data.json` 에 저장되고,
기기마다 GitHub 토큰(그 저장소 Contents 읽기/쓰기 권한만)을 한 번 넣으면 읽고 쓴다.
